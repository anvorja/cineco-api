# Legacy Monolith

Esta carpeta conserva el monolito original del proyecto.

Estado esperado:

- legado
- fuera del flujo activo de microservicios
- no usar como referencia funcional para nuevas implementaciones

Notas:

- El flujo vigente de compras debe evaluarse contra `booking-service`, `inventory-service`, `payment-service`, `catalog-service` y `notification-service`.
- Si se consulta este código, debe hacerse solo con contexto histórico o de migración.
